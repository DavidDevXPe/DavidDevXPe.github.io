El proyecto

Aplicación web interactiva inspirada en Pokémon que permite al usuario ingresar como entrenador, consultar Pokémon, realizar búsquedas por nombre, filtrar por tipo y navegar entre los resultados mediante paginación.

Consume información de PokeAPI y muestra datos como tipo, HP, ataque, defensa, ataque especial, defensa especial y velocidad.

Lo que aprendí

Aquí el diseño me costó tanto como la lógica: acomodar los datos de cada Pokémon en tarjetas legibles, sin que la información se viera apretada, me tomó más iteraciones que el propio filtro o la paginación.

También reforcé el consumo de APIs REST con Axios, el manejo de estado global con Redux Toolkit, la navegación con React Router y el despliegue frontend en Vercel.

PROYECTO 02 / PUBLICADO

Rick and Morty App

Abrir demo ↗ Ver código
El proyecto

Aplicación web desarrollada con React que consume la Rick and Morty API para consultar ubicaciones del universo de la serie y visualizar los personajes que habitan en cada una.

Permite buscar ubicaciones por identificador y muestra su nombre, tipo, dimensión y número de residentes. Cada personaje incluye imagen, estado, especie, origen y cantidad de episodios.

Lo que aprendí

Este proyecto marcó el punto donde los hooks dejaron de ser un obstáculo: construí un custom hook para manejar las peticiones y los estados de carga y error, algo que al inicio de mi formación me costaba entender.

También practiqué useState, useEffect, useRef, el consumo de APIs REST con Axios, paginación de datos externos y despliegue en Vercel.

Tecnologías
  • React
  • JavaScript
  • Vite
  • CSS
  • Axios
  • Rick and Morty API
  • Vercel

PROYECTO 03 / PUBLICADO

Weather App

Abrir demo ↗ Ver código
El proyecto

Aplicación web del clima desarrollada con React que utiliza la ubicación actual del usuario mediante la geolocalización del navegador para consultar información meteorológica en tiempo real.

Consume OpenWeatherMap y muestra ciudad, país, descripción, temperatura, viento, nubosidad, presión y humedad. También permite cambiar entre grados Celsius y Fahrenheit.

Lo que aprendí

La parte más entretenida fue trabajar con datos del mundo real: pedir la ubicación al navegador mediante la Geolocation API y convertir la temperatura que devuelve OpenWeatherMap (en Kelvin) a Celsius y Fahrenheit.

Además practiqué el consumo de APIs REST con Axios, useState y useEffect, y el despliegue en Vercel.

  • Vite
  • CSS
  • Axios

  • Vercel
